# Carpeta de Contexto

Esta carpeta almacena documentos (PDFs, etc.) que el chatbot puede usar como contexto adicional.

- Coloca aquí archivos PDF para que el agente de Llama Cloud los parseé.
- La API acepta `pdf_path` relativo a la raíz del backend (ej. `./context/mi_documento.pdf`).

Ejemplo: `attention_is_all_you_need.pdf` - Paper sobre transformers.
