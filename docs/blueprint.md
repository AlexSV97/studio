# **App Name**: MemoryPal Chat

## Core Features:

- Conversational Interface: Provide an intuitive chat interface for users to type messages and view bot responses.
- User Name Storage & Recall Tool: Allows the chatbot to remember and recall the user's name ('Me llamo X' and '¿Cómo me llamo?'), storing it in a local JSON file.
- User Preference Storage & Recall Tool: Enables the chatbot to store user preferences ('Me gusta X') and recall them when asked ('¿Qué me gusta?'), using the local JSON file for persistence.
- Persistent JSON Data Storage: Manages reading from and writing to a local JSON file to ensure all user names and preferences are saved and persist across chat sessions.
- Basic Query Understanding Tool: A lightweight AI tool that analyzes simple user queries to determine whether to store new information (name, preference) or retrieve existing information from memory.

## Style Guidelines:

- Primary interactive color: A serene and thoughtful blue-violet, `#483BDC`, symbolizing clarity and depth in conversation.
- Background color: An exceptionally light and desaturated blue-purple, `#F0EFF4`, providing a clean, airy, and calming canvas for interaction.
- Accent color: A soft and vibrant sky blue, `#79A9EB`, to highlight key information or call-to-action elements, maintaining visual harmony.
- Main font: 'Inter', a modern sans-serif typeface, recommended for all text (headlines and body) due to its exceptional readability and neutral, objective aesthetic, perfect for a conversational interface.
- Use minimalist and crisp line-art icons that subtly convey actions like sending a message or managing settings, maintaining a clean and modern look.
- Employ a clean, focused, single-column layout for the chat interface to emphasize conversation flow and minimize distractions, with clear visual separation between user and bot messages.
- Incorporate subtle, fluid transition animations for new message arrivals or interface element changes, enhancing the user experience without being intrusive.
